# Changelog

## v1.0.0 (2026-09-28)

First public release.

- **edge-tts-voiceover** plugin: free Microsoft neural voice-overs with voice, speed and pitch choice, delivery tags, SRT subtitles and word timings. Commands: `/edge-tts-voiceover:voiceover`, `/edge-tts-voiceover:voices`.
- **autonomous-motion-videos** plugin: narrated explainer videos rendered from code with Remotion, word-synced captions, optional Three.js 3D and AI images. Includes a starter template and a 96-second reference project. Commands: `/autonomous-motion-videos:explainer-video`, `/autonomous-motion-videos:new-video-project`.
- Claude Code plugin marketplace (`agent-motion-studio`), skills.sh support, and Claude.ai upload zips in `dist/`.
